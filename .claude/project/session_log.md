Wired real models: chat `gpt-oss:20b` on Ollama Cloud, embeddings `nomic-embed-text` on the LOCAL daemon (ollama.com serves chat models, not embedding models). **GLM is subscription-gated** — glm-5.2 and glm-5.1 both return "this model requires a subscription" on the user's key; gpt-oss:20b and gemma4:31b verified callable. ChatModel is pure config, so switching back is one line. Semantic matching confirmed: a React resume ranks a "Modern JavaScript UI framework" posting first at 75.4% semantic with no shared keyword. **Measured finding that changed the design:** cosine over skill NAMES cannot separate adjacent from unrelated on either local model, across 5 prefix strategies (nomic bare: adjacent median 0.379 vs unrelated 0.383); worse, equivalent and non-equivalent overlap too (highest false 0.701 > lowest true 0.430). So transferability moved to a new `SkillTransferService` (LLM, choosing only from the candidate's real skill list, every returned pair re-grounded against both lists), and `SkillEquivalenceMin` was recalibrated to 0.72 — set above the highest observed FALSE positive rather than below the lowest true one, because a false "Have" tells a candidate they are covered for something they cannot do. At 0.55 it reported CSS satisfied by JavaScript. Result on the test pair: 63.9%→72.3%, verdicts now React→component architecture, Redux→state management, SCSS→CSS, and zero false transfers on the unrelated DevOps job. Also completed Copilot mode: new `frontend/src/state/PortalState.tsx` owns board filters + the bot's shortlist, so chat commands drive the actual job-board grid, with a "Filtered by the assistant / Show all roles" banner so a filtered grid is never mistaken for an empty board.
